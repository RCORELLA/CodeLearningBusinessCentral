# CodeLearningBusinessCentral

Code for hands-on AL development exercises for Business Central, published on the **Aprende Business Central en Español** channel.

Each folder is a standalone exercise (a self-contained AL project, with its own `app.json`), meant to go alongside a video or blog post. You can clone the whole repo or just download the folder for the exercise you're interested in.

## Available exercises

| Exercise | Description | Video |
|---|---|---|
| [ABCIsolate](./ABCIsolate) | How to store API keys and passwords securely using Isolated Storage and SecretText | [YouTube](https://www.youtube.com/watch?v=zKk-W6QoS7E) |

*(More exercises will be added here over time, such as Scaffolder.)*

## How to use these exercises

1. Clone the repo, or download the folder for the exercise you want.
2. Open it in VS Code with the AL Language extension installed.
3. Each folder has its own `README.md` with the specific explanation and steps to try it out.
